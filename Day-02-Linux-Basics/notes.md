# Linux Basic Commands

## File & Directory Commands
- `ls` - List files and folders
- `ls -ltr` - Detailed list with permissions, size, timestamp
- `pwd` - Show current directory
- `cd` - Change directory
- `cd ..` - Move up one level
- `cd ../..` - Move up two levels
- `touch filename` - Create empty file
- `vi filename` - Open file for editing
- `cat filename` - Print file content
- `mkdir` - Create new directory
- `rm filename` - Delete a file
- `rm -r foldername` - Delete a directory

## System Info Commands
- `free` - Show memory usage
- `free -mg` - Memory in megabytes
- `nproc` - Show number of CPUs
- `df -h` - Disk space usage
- `top` - Real-time running processes
