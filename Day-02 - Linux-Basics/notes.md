# 🐧 Linux Basic Commands
## 📅 Date: 27-02-2026
## ✅ What I Learned Today:
- How to list files and folders in terminal
- How to navigate between directories
- How to create and delete files and folders
- How to view file content and system info
- How to use the VI editor for editing files

## 📝 Commands:
| Command | Description |
|---------|-------------|
| `ls` | lists files and folders in current directory |
| `ls -ltr` | shows detailed list with permissions, ownership, size & timestamp |
| `pwd` | shows present working directory |
| `cd` | change directory |
| `cd ..` | move up one directory level |
| `cd ../..` | move up two directory levels |
| `touch` | creates an empty file |
| `vi` | opens a file for editing |
| `cat` | displays file content in terminal |
| `mkdir` | creates a new directory |
| `rm` | deletes a file |
| `rm -r` | deletes a directory |
| `free` | displays free and used memory |
| `free -mg` | displays memory in megabytes |
| `nproc` | shows number of available CPUs |
| `df -h` | shows disk space usage in readable format |
| `top` | real-time view of running processes |

## 🖥️ VI Editor Steps:
```
1. vi filename     → open file
2. Press ESC + I   → enter insert mode
3. Type content
4. Press ESC + :wq → save and quit
```
